Google Workspace / 17 tools / REST v1

Apps Script,
from any agent.

Read code, push changes and update a deployment through Google's API. Keep the web-app URL your users already know.

No local clasp installation. Broker-owned Google credentials.

Verification: examples below use mock fixtures. Real Google integration awaits an authorized scratch-project test. Writes require explicit server enablement.

Publish without changing the link

content_get → content_update (upsert) → version_create → deployment_update → script_processes_list

Use the existing deployment ID. A new deployment creates a new URL. Upsert preserves omitted files; full replacement deletes them. Concurrent editor changes can race the read-merge-write operation.

Connect once, then call

  1. Enable Apps Script API in your Google Cloud project and at Google Apps Script user settings.
  2. Connect broker provider google-appsscript for the intended agent. Request script.projects, script.deployments, script.processes, script.metrics and drive.readonly (or drive.file).
  3. Attach https://appsscriptmcp.agenticledger.ai/mcp with a Google Bearer token, gateway-signed broker principal, or private persistent caller key. Keep credentials in the platform's secure connection flow.
  4. The approved Railway production profile enables writes with APPS_SCRIPT_ENABLE_WRITES=true; ordinary local startup stays read-only. Verify /health before publishing and first test a scratch project.

Running functions: an API-executable deployment must share the OAuth client's standard GCP project, and the token needs every scope used by the script. Process history exposes statuses and timing; full logs remain in Google Cloud Logging / Apps Script Executions.

The inspected broker provider currently requests only script.projects. Its owner must expand the scopes and users must re-consent before the other capabilities work.

content_update

Push files. Default upsert reads HEAD, merges by name and type and preserves omitted files. replace DELETES all omitted files and needs confirmReplace=true. Both write the complete file set; concurrent editor changes can race even with expectedContentHash. HEAD changes affect triggers immediately. OAuth: https://www.googleapis.com/auth/script.projects. Requires APPS_SCRIPT_ENABLE_WRITES=true.

Example arguments

{
  "scriptId": "scratch-script",
  "mode": "upsert",
  "files": [
    {
      "name": "Code",
      "type": "SERVER_JS",
      "source": "function ping() { return \"pong\"; }"
    }
  ]
}

Input schema

{
  "type": "object",
  "properties": {
    "scriptId": {
      "type": "string",
      "pattern": "^[A-Za-z0-9_-]{1,256}$"
    },
    "files": {
      "anyOf": [
        {
          "type": "array",
          "items": {
            "type": "object",
            "properties": {
              "name": {
                "type": "string",
                "minLength": 1,
                "maxLength": 256
              },
              "type": {
                "type": "string",
                "enum": [
                  "SERVER_JS",
                  "HTML",
                  "JSON"
                ]
              },
              "source": {
                "type": "string",
                "maxLength": 4194304
              }
            },
            "required": [
              "name",
              "type",
              "source"
            ],
            "additionalProperties": false
          },
          "minItems": 1,
          "maxItems": 200
        },
        {
          "allOf": [
            {
              "type": "string",
              "maxLength": 8388608
            },
            {
              "$ref": "#/properties/files/anyOf/0"
            }
          ]
        }
      ]
    },
    "mode": {
      "type": "string",
      "enum": [
        "upsert",
        "replace"
      ],
      "default": "upsert"
    },
    "confirmReplace": {
      "type": "boolean"
    },
    "expectedContentHash": {
      "type": "string",
      "pattern": "^[a-f0-9]{64}$"
    }
  },
  "required": [
    "scriptId",
    "files"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}

script_run

Run a function using deploymentId (API-executable deployment ID, not project ID); may change data. Legacy scriptId is an alias for that deployment ID. Requires the SAME standard GCP project as the OAuth client; token must cover ALL script scopes. No service accounts. devMode is for the script owner. A run can return Operation.error despite HTTP 200. OAuth: All OAuth scopes declared/used by the target script (no universal script.run scope). Requires APPS_SCRIPT_ENABLE_WRITES=true.

Example arguments

{
  "deploymentId": "scratch-api-deployment",
  "functionName": "ping"
}

Input schema

{
  "type": "object",
  "properties": {
    "deploymentId": {
      "type": "string",
      "pattern": "^[A-Za-z0-9_-]{1,256}$",

    "scriptId": {
      "$ref": "#/properties/deploymentId",
      "description": "Deprecated alias for deploymentId; use the API-executable deployment ID, not the project ID"

      "type": "string",
      "maxLength": 256,

    "parameters": {
      "anyOf": [
        {
          "type": "array",
          "items": {},
          "maxItems": 100
        },
        {
          "allOf": [
            {
              "type": "string",
              "maxLength": 1048576
            },
            {
              "$ref": "#/properties/parameters/anyOf/0"
            }

        }
      ]
    },
    "devMode": {
      "type": "boolean",
      "default": false
    }
  },
  "required": [

  ],
  "additionalProperties": false,
